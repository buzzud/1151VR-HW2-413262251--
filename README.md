## ⌨️ 鍵盤操作說明

| 按鍵 | 動作 | 說明 |
| :---: | :--- | :--- |
| **`A`** | 向左移動 | 控制企鵝往左方移動 |
| **`D`** | 向右移動 | 控制企鵝往右方移動 |
| **`Space`** | 跳躍 | 跨越平台斷層與障礙物 |
